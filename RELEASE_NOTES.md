# Piggy 0.2.2.0 — Debt Groups

- Di halaman Debt, pilih hutang lalu buka **Edit Details → Debt Group**. Ketik nama grup baru atau pilih grup yang sudah ada. Kosongkan kolom untuk mengeluarkan hutang dari grup.
- Pilih grup untuk melihat total pokok hutang, jumlah yang sudah dibayar, dan sisa hutang. Pilih salah satu hutang untuk mencatat pembayaran pada hutang tersebut.

Dokumen lama dapat dibuka dengan semua hutang awalnya berada di luar grup. Saat disimpan, dokumen memakai format **13**. Simpan salinan file lama jika masih perlu membukanya dengan Piggy 0.2.1.2.
