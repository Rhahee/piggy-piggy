# Piggy - Piggy 0.1.0.0 — Initial Development Baseline

**0.1.0.0** is the initial development baseline for Piggy - Piggy, a portable Windows application for personal finances across multiple bank accounts.

- Includes bank accounts, Income/Expense/Transfer, both Income fee bases, automatic Admin Fee rows, Purpose allocations, Period/Pay Cycle, Wishlist and Debt/Self Debt.
- Retains compact transaction icons, complete tooltips for long text, flexible amount searches and fresh/retryable update checks.
- Document format remains **9**. Formats 1–8 still open without rewriting the original until Save. Manual Save/Open behavior is unchanged.
- The new update generation prevents the app from offering the old experimental 1.x/0.5.x builds. Future updates within the new baseline remain automatic.

## Installation

Extract the portable package into a writable folder and run **Piggy - Piggy.exe**. If replacing a previous build, **Save** and close it first, then **Open** the same .mpb document in this version. EXE updater backups are separate from finance-document backups.

The repository starts at one baseline commit with tag **app-v0.1.0.0**. Previous experimental history and release packages are archived separately. GitHub Latest identifies this baseline; the existing published application package remains unchanged by the repository cleanup.

Validation details and coverage limits are recorded in docs/VERIFICATION.md.
