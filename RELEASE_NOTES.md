# Piggy 0.2.1.1 — Shared Budget Goals Table

- Shared Budget menampilkan **Goal**, **Allocated**, **Estimate**, dan **Remaining** dalam kolom terpisah.
- **Unassigned balance** tampil di baris pertama tepat di bawah header.
- Tombol **Edit** dan **Delete** sejajar di kanan. Tabel bisa digeser secara horizontal saat panel sempit.

Paket portable dan web installer Windows x64 tersedia dengan checksum SHA-256.
