# Piggy - Piggy 0.1.0.0 — Initial Development Baseline

The first published baseline of **Piggy - Piggy**, a portable C#/WPF application for Windows x64. English interface, magenta ribbon, Rupiah amounts (`Rp 1,250,000.00`) and dates in `MM/DD/YYYY`.

## Included features

- Multiple bank accounts with Income, Expense and transfers between your own accounts.
- Required Income/Expense categories, separate Admin Fees, and both Before fee / After fee Income modes.
- Purpose allocations and persistent Calendar Month, Custom Range and Pay Cycle periods.
- Wishlist with bank-specific allocations, purchases, release balancing and activity corrections.
- Debt and Self Debt tracking linked to transactions, with repayments and manual settlement confirmation.
- Manual New / Open / Save / Save As, unsaved-change warnings, transaction search, compact icons and complete tooltips.

## Download and run

1. Download **Piggy-Piggy-0.1.0.0-win-x64.zip** and extract it into a writable folder.
2. Run **Piggy - Piggy.exe**. Installing .NET is not required.
3. Choose New or Open an existing `.mpb` document. Save manually with Ctrl+S.

The `.zip.sha256` asset contains the SHA-256 checksum for verifying the download. Your financial documents remain separate from the portable application files.

## Compatibility and scope

Document format **9**, compatibility with formats **1–8**, and update epoch **3** are retained. Opening an older document does not rewrite it until Save.

This release uses the baseline application's custom title bar. **The native Windows window-frame change belongs to 0.1.0.1, which remains in development and is not included in this release.**
