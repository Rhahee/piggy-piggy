# Piggy 0.1.1.0

**Perbaikan Fitur — Web Installer and Display Fixes**, 9 November 2026.

- [Halaman rilis](https://github.com/Rhahee/piggy-piggy/releases/tag/app-v0.1.1.0).
- [Web installer Windows x64](https://github.com/Rhahee/piggy-piggy/releases/download/app-v0.1.1.0/Piggy-Piggy-Web-Setup-win-x64.exe) dan [SHA-256](https://github.com/Rhahee/piggy-piggy/releases/download/app-v0.1.1.0/Piggy-Piggy-Web-Setup-win-x64.exe.sha256).
- [Portable Windows x64](https://github.com/Rhahee/piggy-piggy/releases/download/app-v0.1.1.0/Piggy-Piggy-0.1.1.0-win-x64.zip) dan [SHA-256](https://github.com/Rhahee/piggy-piggy/releases/download/app-v0.1.1.0/Piggy-Piggy-0.1.1.0-win-x64.zip.sha256).

Rilis ini menyediakan web installer yang mengikuti kanal resmi GitHub, menolak downgrade, dan memverifikasi paket sebelum memasang. Aplikasi menyertakan perbaikan ukuran/posisi jendela pada perubahan DPI, sinkronisasi versi pada daftar aplikasi Windows setelah update, serta mutex untuk pemasangan ulang. Dokumen format 9, kompatibilitas format sebelumnya dan updater epoch 3 tetap dipertahankan.

Web installer tetap dapat dipakai untuk rilis aplikasi berikutnya selama protokol kanal/paket dan mekanisme pemasangan tetap kompatibel. Paket portable tetap merupakan sumber pembaruan aplikasi. Internet hanya diperlukan untuk pemasangan melalui web installer dan pembaruan; penggunaan dokumen tetap offline.

Lihat [panduan installer](../INSTALLER.md) dan [bukti verifikasi](../VERIFICATION.md). Batas pengujian: transisi DPI fisik lintas monitor dan Windows bersih belum diverifikasi; installer belum ditandatangani digital.
