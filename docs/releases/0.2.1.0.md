# Piggy 0.2.1.0 — Shared Budget Progress & Goal Deletion

- Progress bar di daftar dan detail Wishlist membandingkan total saldo Shared Budget dengan jumlah estimasi goal aktif. Goal tanpa estimasi tetap tersedia untuk pembelian.
- Tombol **Delete** menghapus goal dari daftar aktif dan menghitung ulang target grup. Alokasi yang tersisa kembali ke **Unassigned balance** pada rekening yang sama. Catatan pembelian tetap tersedia dan masih bisa dikoreksi.

Piggy dapat membuka dokumen format 11 dan versi sebelumnya. Saat disimpan, dokumen memakai format 12 agar goal yang dihapus tidak muncul kembali di versi lama. Buat salinan sebelum menyimpan jika dokumen masih perlu dibuka di 0.2.0.0.

Rilis Windows x64 menyediakan paket portable serta web installer dengan checksum SHA-256.
