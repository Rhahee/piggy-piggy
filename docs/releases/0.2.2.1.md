# Piggy 0.2.2.1 — Grup Debt dan Wishlist

- **New Debt Group** di sebelah kanan **New Debt** membuat grup yang bisa disimpan meski masih kosong. Untuk memasukkan hutang yang sudah ada, buka **Edit Details → Debt Group**.
- **New Wishlist Group** di sebelah kanan **New Wishlist** langsung membuat Shared Budget. Gunakan **Add Goal** untuk menambahkan tujuan.

Membuka dokumen lama tetap didukung. Saat disimpan, file memakai format **14**. Simpan salinan lama jika masih perlu membukanya di Piggy 0.2.2.0.
