# Review bug ikon MPB — 0.1.1.1 unreleased

Pemeriksaan 9 November 2026 menemukan **satu bug terkonfirmasi (P2)** pada cleanup asosiasi berkas. Kode installer belum diperbaiki dalam pemeriksaan ini. Paket yang ditinjau adalah revisi installer lokal 1.0.0.1; SHA-256 `937ef3786241a94d9f334e516e2871a10851c953acc93c69f7604a362458adc0`.

**Tindak lanjut:** bug sudah diperbaiki untuk [rilis 0.1.1.1](../releases/0.1.1.1.md). Marker `DocumentDefaultOwner` disimpan per AppId dan folder instalasi ketika setup mengambil default. Uninstaller membacanya sebelum cleanup registry dan hanya membersihkan default dengan pemilik/lokasi yang cocok. Marker bertahan saat pemasangan ulang opt-out. Uji regresi pada kode lama gagal sesuai bug; sesudah perbaikan, **37 pemeriksaan asosiasi lulus**. Uraian dan hash di bawah merupakan bukti historis sebelum fix.

## P2 — Uninstall menghapus default lama meskipun registrasi tidak dipilih

Lokasi: `installer/Piggy.iss`, `CurUninstallStepChanged`, baris 97–101 pada sumber yang ditinjau.

Callback uninstall hanya membandingkan nilai default ekstensi dengan ProgID Piggy. Callback tidak memeriksa apakah instalasi ini pernah memilih tugas `fileassociation` atau memiliki nilai default tersebut. Karena callback berjalan terlepas dari pilihan tugas, default yang sudah ada sebelum pemasangan dapat dihapus oleh instalasi yang tidak pernah mendaftarkannya.

Reproduksi memakai installer QA yang sudah dikompilasi dari aturan produksi, dengan AppId/ProgID/ekstensi terpisah:

1. Siapkan default ekstensi QA ke ProgID Piggy QA, beserta ProgID dan ikon fiktif yang merepresentasikan registrasi sebelumnya.
2. Jalankan installer dengan `/TASKS=""` agar registrasi dokumen tidak dipilih.
3. Setelah install, default dan ikon sebelumnya masih utuh; ini memastikan tugas registrasi memang dilewati.
4. Jalankan uninstaller. Default ekstensi menjadi tidak ada, sedangkan ProgID sebelumnya masih ada.

Hasil tercatat sebagai `BugReproduced=true`. Dampaknya adalah hilangnya default pembuka untuk berkas yang sebelumnya terkait ke ProgID Piggy, walaupun pengguna tidak memilih registrasi pada pemasangan baru. Dokumen keuangan tidak terhapus. Pilihan Windows UserChoice yang terlindungi tidak ditulis atau dihapus oleh pengujian ini.

Perbaikan yang disarankan: simpan penanda kepemilikan default saat pemasangan benar-benar membuat/mengambilnya untuk instalasi tersebut. Uninstaller harus memeriksa penanda dan lokasi instalasi pemilik sebelum membersihkan default yang masih menunjuk Piggy. Penanda harus bertahan pada pemasangan ulang yang menonaktifkan tugas, karena registrasi dari pemasangan pertama masih perlu dibersihkan saat uninstall. Tambahkan kasus default lama + opt-out sebagai regresi.

## Skenario yang lulus

- Pemeriksaan standar asosiasi berkas: **23 pemeriksaan lulus** (ikon melalui Windows Shell, perintah Open yang dikutip, sembilan frame ICO, cleanup registrasi/ikon, pemilik asing, perubahan default setelah pemasangan, dan pelestarian sentinel `.mpb`).
- Tambahan review: **11 assertion lulus** untuk fresh opt-out tanpa registrasi sebelumnya, pemasangan ulang dari opt-in ke opt-out, pelestarian ikon/perintah lama dalam instalasi yang sama, serta cleanup sesudah pemasangan ulang.
- Installer publik dan `update-channel.json` mempertahankan hash sebelumnya. Versi publik tetap 0.1.1.0.

Tidak ada penghapusan dokumen atau perubahan asosiasi `.mpb` pengguna dalam tes ini. Pengujian memakai ekstensi acak di HKCU dan registrasi QA dibersihkan setelahnya. Windows UserChoice, double-click pada dokumen asli, dan Windows bersih belum dicakup.
